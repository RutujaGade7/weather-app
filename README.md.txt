# Weather App 🌦️

A simple and responsive Weather App built using HTML, CSS, and JavaScript.

Users can enter any city name and get:
- Current temperature
- Weather condition
- Humidity
- Wind speed

---

## 🚀 Features

- Search weather by city name
- Real-time weather data using WeatherAPI
- Responsive UI
- Clean and modern design

---

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- WeatherAPI
